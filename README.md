# Quiz Platform — Frontend

TanStack Start (Vite + React 19) with Tailwind CSS v4, Framer Motion, Recharts.

## Dev Commands

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production build
npm run typecheck  # tsc --noEmit
```

## Ports

| Service | Port |
|---------|------|
| Frontend (Vite) | 3000 |
| Backend (Wrangler) | 8787 |

## Environment

Copy `.env.example` to `.env` and set values as needed.
